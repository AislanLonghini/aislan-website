🚀 Aislan Longhini — Executive IT & Delivery Manager Portfolio

Portfólio executivo de alta performance desenvolvido com uma estética moderna inspirada em *Liquid Glass* e padrões de design da Apple / *The Startup* (Hover.dev). O projeto foi concebido para destacar a sólida experiência em Liderança de Tecnologia, Transformação Digital, Governança (SAFe 6.0 RTE) e Integração de Negócios e Dados.


## 💡 A Jornada do Projeto: Da Ideia à Implantação

O desenvolvimento seguiu uma abordagem estruturada baseada em engenharia de software moderna, prototipagem rápida e foco absoluto em experiência do usuário (UX):

1. **Concepção & Identidade Visual (UI/UX)**:
   - Definição do conceito visual **Liquid Glass** (translucidez, cartões em *bento grid*, gradientes dinâmicos de luz e efeitos de *backdrop-blur*).
   - Organização de seções estratégicas: Resumo Executivo, Competências, Linha do Tempo Profissional, Certificações Internacionais (MIT, Anthropic, FIAP) e Recomendações Profissionais estruturadas por nível hierárquico.

2. **Desenvolvimento Tecnológico**:
   - Construção com **React**, **Vite** e estilização avançada via **Tailwind CSS**.
   - Criação de uma navegação fluida por abas e inclusão de uma aba exclusiva de **Contato Direto** (E-mail e WhatsApp corporativo).

3. **Controle de Versão & Gestão no GitHub**:
   - Inicialização do repositório Git local e sincronização com o repositório remoto oficial: [`AislanLonghini/aislan-website`](https://github.com/AislanLonghini/aislan-website).
   - Gerenciamento de commits e versionamento contínuo através da interface gráfica do VS Code.

4. **Implantação (Deploy) Automatizada na Vercel**:
   - Integração contínua entre o GitHub e a **Vercel**, garantindo que qualquer alteração de código enviada (*push*) atualize automaticamente o site em produção.
